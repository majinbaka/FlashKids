# Issues

Problems found while working on something else. FlashKids' rule is that a
discovered issue is **logged here, not fixed in place** — an unrelated fix
enlarges the diff and hides the change under review.

- One issue per file, named `YYYY-MM-DD-short-slug.md`.
- Copy `TEMPLATE.md` and fill every section.
- `status:` is `open`, `fixed`, or `wontfix`. When one is fixed, set the status
  and reference the commit rather than deleting the file.

Exceptions: fix it now if the issue *is* the task, if the requested change is
wrong without the fix, or if the user asks. If it blocks you, file it and stop
to report the blocker.

See `.claude/skills/log-issue/SKILL.md` for the full procedure.
